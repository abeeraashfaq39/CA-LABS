## 🛠️ Software & Tools Used

- **Proteus Design Suite 8** — Schematic capture and circuit simulation
- **Multisim** — Secondary simulation verification
- **Virtual Instruments:** DC Ammeter, Voltmeter, Oscilloscope, Function Generator
- **Hardware:** Breadboard, carbon film resistors (330Ω, 1kΩ),
  connecting wires, DC Power Supply

## 📐 Core Concepts Covered

- Verification of Ohm's Law and Kirchhoff's Laws (KVL / KCL)
- Network Theorems — Thevenin's, Norton's, Maximum Power Transfer, Superposition
- Transient response of RC, RL, and RLC circuits
- AC circuit analysis, phasor diagrams, and resonance phenomena
